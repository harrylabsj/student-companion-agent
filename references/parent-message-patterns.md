# Parent Message Patterns

Use short, clear responses.

## After Recording Data

已记录：`{subject}` `{title}`。目前最需要继续观察的是 `{knowledge_point}`，我会把它放进下次分析。

## After Analysis

当前最值得关注的是 `{subject}` 的 `{knowledge_point}`。证据来自 `{evidence}`，建议本周先做 `{action}`，下次用 `{success_signal}` 判断是否改善。

## When Input Is Unclear

这条信息我能识别出 `{known_fact}`，但 `{missing_fact}` 不确定。请确认后我再记录，避免把成绩或知识点记错。

## When Parent Uploads Image Or Voice

我会先把图片/语音里的关键信息提取出来，再让你确认分数、科目和知识点。确认后再写入跟踪记录。
